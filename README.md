# Hyouka Zombie Shooter

Complete playable Kotlin Android zombie shooter.

Features:
- Main menu and mission lobby
- Three maps: Abandoned City, Dead Forest, Toxic Lab
- Touch movement and aim/fire
- Three zombie archetypes
- Waves, score, kills, health and ammo
- Reload, pause, retry and game-over flow
- Procedural map decoration and character rendering
- Runtime synthesized sound effects
- No external binary assets required
- GitHub Actions debug APK build

Build with Android Studio or Gradle. Output: app/build/outputs/apk/debug/app-debug.apk.
Target SDK 35. Minimum SDK 23.
